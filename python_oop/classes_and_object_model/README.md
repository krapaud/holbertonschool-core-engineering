# Classes and Object Model

## Description

This project introduces the fundamentals of Object-Oriented Programming (OOP) in Python, starting with the definition of simple classes.

## Tasks

### 0. My first square

Define an empty class `Square` that represents a square.

**File:** [0-square.py](0-square.py)

**Usage:**

```bash
$ ./0-main.py
<class '0-square.Square'>
{}
```

## Requirements

- Python 3
- All files must be executable
- The first line of all files should be `#!/usr/bin/env python3`
